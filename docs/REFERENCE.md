# Сведения о присланном ELF all-in-one

Исходный ZIP: `allinOne_full_29.10.26.zip`. Сторонний бинарник **не включён** в этот GitHub-репозиторий.

Статический анализ примера, использованного при проектировании:

- внешний файл: FreeBSD ELF PIE для x86-64, 7 877 776 байт;
- SHA-256: `3f4b3d0e26dda948790616202e278a713aec942c45f20d8ff7b2c66353ff0244`;
- посылает шесть вложенных ELF по TCP на `127.0.0.1:9021`;
- отправляет их последовательно, в отдельных соединениях, с интервалом 1000 мс;
- при подключении делает до 30 попыток с задержкой 100 мс.

| Нагрузка | Размер (байт) |
|---|---:|
| kstuff.elf | 1 835 112 |
| elfldr.elf | 394 568 |
| ftpsrv.elf | 230 640 |
| nanodns.elf | 132 352 |
| websrv.elf | 1 599 288 |
| shadowmountplus.elf | 3 580 320 |

Строка в ELF kstuff из примера содержит `Welcome To Kstuff Lite 1.13-fpkg-dr-test7-restmode`, то есть **test7**, а не test8.

Статический анализ не подтверждает безопасность и работоспособность на конкретной прошивке. Сборщик воспроизводит принцип передачи ELF, но не является побайтовой копией исходного AIO.
