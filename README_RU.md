# PS5 AIO Builder — инструкция (русский)

Репозиторий: https://github.com/Vov4k957/ps5-aio-builder

**Назначение:** собирать ELF-нагрузку «всё в одном» из выбранных ELF, автоматически получая самые свежие релизы из исходных репозиториев GitHub. Получившийся ELF последовательно отправляет вложенные нагрузки на локальный загрузчик консоли `127.0.0.1:9021`.

**Важно:** проект экспериментальный. Успешная компиляция не доказывает работоспособность на PS5 13.60. Это не эксплойт, не Y2JB и не средство запуска FPKG само по себе.

## Сборка через GitHub Actions

1. Открой вкладку **Actions**.
2. Слева выбери **Build PS5 AIO**.
3. Нажми **Run workflow**, выбери `standard`, `extended` либо `zftpd`.
4. В завершившемся запуске скачай ZIP из раздела **Artifacts**.
5. Изучай `manifest.json`: там будут версии, URL источников, размеры и SHA-256 каждого ELF.

Сценарий также автоматически собирает профиль `standard` раз в сутки. Он не публикует GitHub Releases автоматически и не загружает файлы на консоль.

**Репозиторий публичный.** Никогда не загружай в него Discord-only бинарники, если их автор не разрешил распространение. Артефакты публичного GitHub Actions не следует считать закрытым хранилищем.

## Профили

| Профиль | Состав |
|---|---|
| `standard` | Публичный kstuff от EchoStretch, elfldr, ftpsrv, nanoDNS, websrv, ShadowMountPlus |
| `extended` | То же, плюс klogsrv и Dump Forge |
| `zftpd` | Как standard, но zftpd вместо ftpsrv |
| `fpkg13` | То же, но вместо публичного kstuff — твой локальный `kstuff1.13-fpkg-dr-test8-restmode.elf` |

Первые три профиля доступны через GitHub Actions. **fpkg13 — только для локального запуска**, поскольку исходник kstuff из Discord пока недоступен на GitHub и не должен автоматически публиковаться.

## Как собирать локально с Discord-нагрузкой

На Linux установи [PS5 Payload SDK](https://github.com/ps5-payload-dev/sdk) по инструкции разработчика, задай `PS5_PAYLOAD_SDK`. Положи свою проверенную нагрузку в `manual/kstuff1.13-fpkg-dr-test8-restmode.elf` (точное имя), затем выполни:

```bash
python3 -m unittest discover -s tests -v
python3 scripts/build.py --profile fpkg13
```

Для обычной сборки вместо `fpkg13` используй `standard`. Если вручную добавленного файла нет, программа выдаст ошибку и **не будет** подменять его публичной версией kstuff. Полученные файлы будут в папке `dist/`.

## Расширение состава

В `config/payloads.json` добавь запись с `name`, `kind: github`, `repo: owner/repository`, `asset_regex` и `delay_ms`. После этого включи идентификатор записи в нужный список `profiles` в желаемой последовательности.

Для нагрузки без публичного релиза используй `kind: manual` и `manual_filename`: такие файлы нужно предоставлять локально. Для проверки вручную можно указать `sha256`.

Выбор GitHub осуществляется по времени публикации последнего релиза, включая alpha/beta/prerelease. Если последний релиз не содержит подходящий PS5 ELF, сборка прерывается, вместо того чтобы незаметно брать старую версию.

## Осторожность

- Новейший релиз не означает совместимый с твоей прошивкой релиз.
- Публичный EchoStretch kstuff **не равнозначен** версии Drakmor с экспериментальной поддержкой FPKG.
- Одновременный запуск нескольких FTP-серверов либо конфликтующих патчей ядра может приводить к сбоям.
- Прежде чем запускать новую сборку на PS5, посмотри её manifest и список изменений upstream.
- Исходные сторонние ELF не включены в репозиторий. Права на них принадлежат соответствующим авторам.
