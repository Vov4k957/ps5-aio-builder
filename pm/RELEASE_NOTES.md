PM AutoUpdate 1.2.0 для PM 0.6.3. YT Blocker удалён из каталога, обновления, запуска и старых AIO-профилей. Убраны ожидание закрытия YouTube и отдельная пауза 3 с. Старые настройки поддерживаются: запись блокера игнорируется, отложенный запуск отменяется.

Порядок — nanoDNS, локальный kstuff при наличии, ELF Loader, FTP Server (Drakmor stable), Web Server, ShadowMountPlus, Hush, Dump Forge. Между нагрузками 1 с. Каталог проверяет семь официальных репозиториев каждые 10 минут по расписанию GitHub Actions.

Скачай `pm-autoupdate.elf`, замени предыдущую версию в PM и полностью перезагрузи PS5. Оставь его единственным включённым пунктом автозагрузки PM. Настройки встроены. [Инструкция](https://github.com/Vov4k957/ps5-aio-builder/blob/main/pm/README_RU.md) · [JSON для PM](https://raw.githubusercontent.com/Vov4k957/ps5-aio-builder/main/pm/payloads.json)

При пустой установке запускается встроенный резервный nanoDNS, затем PM скачивает семь публичных нагрузок в отдельные слоты. В дальнейшем скачиваются только отсутствующие, повреждённые или изменившиеся файлы. Аппаратный запуск на PS5 13.60 требует проверки.
