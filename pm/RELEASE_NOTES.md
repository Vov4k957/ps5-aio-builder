Отдельный управляющий ELF для штатного API Payload Manager 0.6.3.

- nanoDNS первым; затем проверка каталога и установка изменившихся публичных ELF через PM.
- kstuff полностью локальный: не скачивается, не публикуется и не обновляется автоматически.
- После проверки — последовательный запуск с паузами прежнего профиля: 1 с / 3 с после ShadowMountPlus / 0 с для последних шагов.
- Сохранённые копии при ошибках и неопределённом результате установки; защита от повторного запуска в одной загрузке PS5.
- nanoDNS обновляется на диске, новая версия запускается при следующей полной загрузке.

**Для установки скачайте `pm-autoupdate.zip` и прочитайте `README_RU.md`.** Нужны отдельные локальные nanoDNS и kstuff. В автозагрузке PM должен остаться только `pm-autoupdate.elf`.

Первая версия: SDK-компиляция и тесты не заменяют проверку на PS5. В частности, запуск nanoDNS до kstuff на FW13.60 требует подтверждения на консоли.
