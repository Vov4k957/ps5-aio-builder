The coordinator transports Drakmor’s unmodified standalone nanoDNS 0.4 for PS5. The seed is read only when a local copy is missing. Its SHA-256 is pinned in `bootstrap/fetch.py`. The corresponding source and build files at commit `21edab7527688979af17d0c828e28065774f5b5c` are included in `bootstrap/nanoDNS-0.4-source.tar.gz` and in the release archive. [Official release](https://github.com/drakmor/nanoDNS/releases/tag/0.4)

The files `third_party/sha256.c` and `third_party/sha256.h` are from itsPLK’s Payload Manager v0.6.3. The distributed coordinator with this code is available under GNU GPL v3. The license text is in `third_party/COPYING`. The repository contains the coordinator source and build scripts. Other payloads are fetched independently from their authors. [PM v0.6.3 source](https://github.com/itsPLK/ps5-payload-manager/tree/v0.6.3)
